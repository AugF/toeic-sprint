# 题目与辅助内容复核（2026-09-24）

## 本轮发现

“字段非空”和“有四个选项”不是内容正确性证明。以前的校验允许英文加中文词注被标记为翻译，允许通用作答建议被当成具体解析；Part 6/7 OCR 更新又会无条件删除原文翻译，因此页面上的按钮与真实可用内容不一致。

本轮保留题目身份、正确选项字母和选项顺序，只修复有依据的内容。Part 5 的原始扫描备份目前缺失：当前目录 `../toeic_listening_reading_banks` 不存在，已检查 Git 历史也没有 Part 5 扫描图。不能把排版重绘的 OCR 文字冒充原始截图。

## 分层处理

1. Part 5：运行 `npm run recover:part5` 生成报告；按题号检查填空、句末、跨栏题号、选项残片。201 题做了确定性的横线、空白、页眉或有证据文本修正；218 题仍需要原始扫描。旧 OCR 和修复来源保留在 `content_review`，疑问题标记 `content_review_status: source_required`。
2. 原图补齐后：按 [源图流程](PART5_RECOVERY_PIPELINE.md) 提交含题库、题号、源图 SHA、人工核对标记与裁剪区域的 manifest。发布真正的单题截图，登记 `asset_refs`，默认显示截图并可放大。合并多题的页面必须先核对印刷题号，不能只按文件顺序分配。
3. 完整句子翻译：`npm run review:part5-aids -- --write` 使用精确句子和答案词匹配应用46条已复核整句中译；将正确答案代入英文后翻译完整句子，中文对应部分用 `**` 强调。数据保存整句和源哈希；源变更时拒绝套用。
4. 听力题干：`npm run review:listening-questions -- --write` 使用150条完整英文→中文的精确映射，修复377题。已有效中文保持不变，其余不合格词注标记待补齐。Official 5 Test 1 Part 4 的98、99题发现材料与选项错配，标记答案待核验并停止判分，不能从现有选项猜补。
5. 阅读辅助：`npm run recover:study-aids -- --write` 仅从历史版本恢复与当前英文逐字段匹配的中文。恢复155条题干翻译、841条选项翻译、1篇原文翻译。解析要求正文、题干、有序选项和答案同时匹配，并排除套话。见 [阅读辅助恢复记录](READING_STUDY_AID_RECOVERY.md)。
6. `npm run sync:reviewed-index` 从当前 detail 更新题型索引、资源引用与内容版本。复核后不应直接用旧原始 OCR 执行 `build:banks` 覆盖这些 detail；如需重建，先输出到独立目录并对照已复核字段。

## 状态契约与展示

- `study_aid_status.question_translation / choice_translations / analysis`：`ready`、`pending`；选项还可以是 `partial`。无独立题干的 Part 6 为 `not_applicable`。
- `pending` 的旧内容不展示为已完成翻译/解析，按钮明确说明尚待补齐。部分选项翻译保留原 A–D 位置，不压缩数组造成错位。
- `answer_review_status: pending` 的题目不会显示确定正确答案，也不判为错题。
- 答案展开只由浏览器保存的 `revealed` 控制。单题、整篇和本页操作更新同一状态；本页批量揭晓需等对应题目数据加载完成。
- 翻译中的 `**` 仅渲染为 React 文本加粗，不执行 HTML。

## 验收和限制

运行 `npm test` 和 `npm run build:pages`，再本地检查默认题库 Part 5 第101题的整句翻译、答案/解析独立展开、跨页回看与当前页清空，以及 Part 6 无题干时不出现空的题干翻译。

本轮没有把所有辅助内容补齐：Part 5 尚有218题等待原图；Part 3/4尚有719题题干翻译待补齐；Part 6/7尚有455篇原文翻译、1,627题详细解析待原文核对和重写。结构测试通过不等于这些内容已经语义正确。报告存于本地 `outputs/`，不应发布为网站资源。修复先本地 review，再由用户决定发布。
