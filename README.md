# TOEIC Sprint

一个面向 TOEIC Listening & Reading 的跨端刷题网站，当前收录 Official 11 Test 1 共 200 题。

## 功能

- Part 1–7 分类练习，听力与阅读按正式考试方式展示
- P1（优先必刷）/ P2（重点巩固）/ P3（基础查漏）筛选与排序
- 全部 200 题均包含训练优先级、重点标签和可解释的定级理由
- Part 3、4、6、7 保持正式题组；Part 5 按连续 5 题组成训练包
- 听力音频、英文原文与中文翻译
- 篇章分组作答、即时对错标记与主动查看解析
- 题型、原文定位、答题技巧和选项释义
- 每题重点单词与短语搭配
- 答题进度保存在当前浏览器中
- 桌面与移动端响应式布局

## 本地运行

```bash
npm install
npm run dev
```

## 优先级口径

定级综合参考 ETS/IIBC 官方考试结构、官方能力描述和现行重点形式，并结合高频考点、题型复现价值、认知难度和迁移价值。P1/P2/P3 是训练顺序，不是 ETS 官方难度或固定出题频率排名。
